# Глобальные пользовательские правила

- Когда пользователь пишет «залей ченжи», это означает только создать локальный Git-коммит с подходящим сообщением. Не выполнять `git push` и не отправлять изменения на удалённый репозиторий, если пользователь отдельно и явно не попросил это сделать.
- Не оставлять пустые строки в конце исходных и конфигурационных файлов. Один завершающий перевод строки после последней содержательной строки допустим.
